### 0a. The five primitives (was three)

Recorded here because the index is what everything else cites, and two of these were missing.

1. **The digest-bound statement** — DSSE → in-toto Statement → `subject[].digest`; the signature covers the pre-authentication encoding of payload and type together. Mint custom predicates freely; **never mint a custom envelope**, because every signature ever issued is over that encoding.
2. **The delegated verdict** — the policy gate, the cross-domain importer and the human reviewer are one pattern, so one implementation, one key story, one audit format. The verdict must record the **policy digest**, and where AI was involved the **model identity and capability-descriptor digest**, so a model swap invalidates prior verdicts exactly as a policy change does. Accept only specific signer-verifier pairs.
3. **The capability descriptor** — must carry **measured** capability (a signed evaluation score), not a hand-maintained list of promises, or it rots like everything else in this file.
4. **Trust configuration** — the keys, roots, revocations and validity windows a verifier needs to check anything. Ambient when connected; **payload** when not. Carries the current root *plus the full chain of previous roots* so a verifier offline for years can walk forward; per-instance validity windows, cumulative and never replaced, because past signatures must still verify; a revocation set with an explicit issue time and a stated policy that anything newer is *unknown* rather than *valid*. Rotation is solved by TUF-style threshold signing. **Bootstrap is not solvable cryptographically** — the first root arrives out of band, which makes it a trusted-*process* problem, and the architecture document must say so.
5. **Freshness and monotonicity state** — `validNotBefore`/`validNotAfter`, a strictly monotonic `sequence` per producer-destination pair, `supersedes`, the receiver-retained high-water mark, and the vulnerability-database version behind any scan verdict. Without receiver-held state an old validly-signed bundle replays and every check passes. See 15.6 for the defect in exactly this mechanism.

### 0b. The five transitions (was four)

A author→source of record; B build→judgement; C low side→high side; D registry→runtime; plus:

**A′ agent→agent — and the recommendation is don't.** Keep agents as leaves; no delegation chains in the core. Two reasons: attribution laundering (a chain destroys the link between a change and an accountable identity), and "independent" verifying agents collapse to very few genuinely corruption-distinct domains, so redundancy buys far less than the agent count suggests.

**Transition C needs a two-control-point split** — see 4.6.

## Research conditions — read before trusting anything above

**No general search engine was available for any of this work.** `WebSearch` does not exist in this session; `WebFetch` failed on every call with `API Error: 400 data retention mode 'default' is not available for this model`. I confirmed both myself. Every general search engine the agents tried was bot-blocked or served CAPTCHAs — Google, Bing, DuckDuckGo, Brave, Mojeek, Startpage and several SearXNG instances. The GitHub REST API rate-limited to zero for parts of the session. **GitHub code search needs authentication, `grep.app` is bot-blocked and `searchcode` is dead — which is why 0.2 happened.**

Everything was gathered by `curl` plus `pandoc`, `git clone --depth 1` and grep, the Wayback CDX API, the arXiv API, the Hugging Face API, and `.md`-suffixed AWS docs URLs. Marginalia was the only working search. Late on, the `r.jina.ai` text-extraction proxy defeated the `.gov` blocking that had stopped everything else, which is the only reason §14 exists.

Three consequences:

1. **Positive findings are unusually strong**, because they come from reading specs, source and primary documents rather than summarising blog posts.
2. **Every negative is weak.** "We found no X" means "not found by directed URL construction and link-following", not "does not exist". Items marked **Weak negative** are the ones to re-check if we ever get search back.
3. **No document may assert a universal negative over open code.** Learned at the cost of a refuted claim (0.2). Where a negative is stated, the method must be stated with it.

A mid-session internet dropout killed all six original agents at the 600-second watchdog; agents now write incrementally for exactly that reason. The adversarial verification workflow was itself resumed after an interruption, which is why the keyless adjudication (0.3) landed last.
